========================================
HOW TO AUTO-START PRINT SERVER ON WINDOWS STARTUP
========================================

METHOD 1: Using Windows Startup Folder (Recommended)
-----------------------------------------------------

Before setting up auto-start, save your actual printer IPs (replace these examples):

   setx PRINTER1_IP "192.168.1.19"
   setx PRINTER2_IP "192.168.1.20"

Omit the second command for a single printer. Sign out and back in so Windows loads
the saved values into programs launched at sign-in.

1. Press Win + R to open Run dialog

2. Type: shell:startup
   Then press Enter

3. This opens the Startup folder

4. Right-click in the folder → New → Shortcut

5. For location, browse to: start-print-server.bat
   (or copy the full path to the bat file)

6. Click Next, give it a name like "Print Server"

7. Click Finish

8. The print server starts automatically after you sign in to Windows. A Startup-folder
   shortcut does not run before the login screen.


METHOD 2: Using Task Scheduler (Runs before login)
---------------------------------------------------

1. Press Win + R, type: taskschd.msc
   Press Enter to open Task Scheduler

2. Click "Create Basic Task" on the right side

3. Name: "Print Server Auto Start"
   Click Next

4. Trigger: "When the computer starts"
   Click Next

5. Action: "Start a program"
   Click Next

6. Program/script: Browse to start-print-server.bat

7. Click Next, then Finish

8. Right-click the task → Properties

9. Under "General" tab:
   - Check "Run whether user is logged on or not"
   - Check "Run with highest privileges"

10. Click OK


TO TEST:
--------
1. Double-click start-print-server.bat
2. You should see the print server starting
3. Leave it running
4. Check each printer at http://localhost:3000/test/printer1 and /test/printer2
5. Open the Vercel site in a browser on this same laptop and print a bill
6. Each configured printer should print its assigned format


TROUBLESHOOTING:
----------------
If the server doesn't start:

1. Make sure Node.js is installed
   Check by running: node --version

2. Install dependencies by running:
   npm install

3. Check a printer at http://localhost:3000/test/printer1 or /test/printer2

The dual-printer server is print-server.js. simple-print-server.js is only for a single printer.
